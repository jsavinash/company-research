# User Help Center Guides

## 1. What is the early-warning system?

It scores SFS's B2B equipment-finance book for default/delinquency risk 3–6 months ahead, using financial data **plus** how the financed machine is actually operated (utilization, downtime, service-deferral, energy). It gives a calibrated PD, a time-to-event estimate, reason codes, and a green/amber/red flag.

## 2. For credit officers

- **Watchlist:** ranked accounts; open one to see:
  - Calibrated PD + time-to-event (P10/P50/P90 months).
  - **Separated attribution:** operational vs. financial-only.
  - Top reason codes in credit language.
  - Similar historical accounts + outcomes.
  - Horizon + confidence statement.
- **Actions:** accept / escalate / restructure / clear → logged as training data.

## 3. Understanding the flags

| Flag | Meaning |
|---|---|
| **Green** | Low risk |
| **Amber** | Watch; possible deterioration |
| **Red** | High risk; prioritize review |

## 4. Understanding the numbers

| Term | Meaning |
|---|---|
| **PD** | Probability of default (calibrated) |
| **P10/P50/P90** | Time-to-delinquency range (optimistic/median/pessimistic) |
| **Reason codes** | Top factors driving the score |

## 5. Troubleshooting

| Issue | Fix |
|---|---|
| Account not scored | Check data completeness / coverage |
| Score seems wrong | Review reason codes; report |
| Stale score | Check data freshness banner |
| No telemetry | Account may not be connected; flag |

## 5. Best practices

- Always review the reason codes before acting.
- Cross-check with your own judgment.
- Report data-join or calibration issues.
