# User Help Center Guides

## 1. What is document extraction?

MyTAXPrepOffice can read uploaded tax documents (W-2, 1099 series, K-1, SSA-1099) and fill the matching fields automatically — with a confidence score on every field. If the system is unsure, it asks you to review that field instead of guessing.

## 2. Uploading a document

1. Go to the client's document area.
2. Upload a PDF or clear photo/scan (avoid glare and skew).
3. The system processes it and shows extracted fields with confidence.
4. Fields marked "review" need your confirmation.

## 3. Reviewing a field

- The reviewer sees the document region, the extracted value, the confidence, and suggested alternatives.
- **Accept** if correct; **correct** if wrong; **reject document** if unreadable.
- Every action is logged (audit + training).

## 4. Understanding confidence

| Confidence | Meaning |
|---|---|
| **High** | Auto-filled; spot-check recommended for high-cost fields |
| **Medium** | Review recommended |
| **Low** | Routed to review queue |

## 5. Troubleshooting

| Issue | Fix |
|---|---|
| Document unreadable | Re-scan at higher DPI; avoid skew |
| Field not extracted | Check the field is in the schema; contact support |
| Wrong value | Correct it in review; it becomes a training label |
| Slow processing | Filing-season peak; try off-peak |

## 6. Best practices

- Upload one document per file.
- Use clear, high-DPI scans.
- Review high-cost fields (TIN, DOB, relationship) carefully.
- Report extraction issues via support.
