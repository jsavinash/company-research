# Magic Moment and Aha Activation

## 1. The magic moment

The moment a planner types a plain-English question and gets a **defensible, explainable answer in seconds** — with P10/P50/P90 numbers, a causal breakdown, and a run ID.

> **Example:** "GLP-1 +5pp in SE → DiGiorno by Q3?"
> **Response:** "By Q3, DiGiorno units −6.2% (P10 −8.1%, P90 −4.4%) vs. plan. Concentrated in 3 banners in 2 DMAs. GLP-1 −2.1pp, price −1.3pp, distribution −0.8pp, private label −0.5pp. Run ID FR-2026-11-22-0142."

## 2. Aha! moments

| Aha moment | What the user realizes |
|---|---|
| **First scenario answer** | "This explains *why*, not just *what*." |
| **Attribution breakdown** | "I can defend this to leadership." |
| **Interval + run ID** | "This is auditable." |
| **Thin-data fallback** | "It knows when it doesn't know." |

## 3. Activation funnel

| Step | Activation event | Target |
|---|---|---|
| 1. Sign-in | First login (Entra ID) | 100% |
| 2. First query | First scenario asked | ≥ 80% of active planners |
| 3. First aha | First causal breakdown viewed | ≥ 60% |
| 4. Habit | Weekly active use | ≥ 80% |
| 5. Advocacy | Shares a run ID / forecast | Report |

## 4. Time-to-value

| Milestone | Target |
|---|---|
| Sign-in → first query | < 5 minutes |
| First query → aha | < 1 minute |
| Onboarding → weekly habit | < 2 weeks |

## 5. Activation tactics

- **Guided first query** — pre-built example questions.
- **Template scenarios** — "GLP-1 +5pp", "price +3%", "distribution loss".
- **In-context explanation** — "why this answer" panel.
- **Shareable run IDs** — easy to forward to leadership.
