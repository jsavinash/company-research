# Domain Glossary

| Term | Definition |
|---|---|
| **Pet profile** | Structured slots (species, breed, age, condition, allergy, preference). |
| **Nutrient adequacy** | Whether a diet meets AAFCO/FEDIAF requirements. |
| **AAFCO / FEDIAF** | Pet food nutrient standards (US / Europe). |
| **Therapeutic diet** | Prescription diet (veterinary channel). |
| **Cold start** | New pet / thin profile. |
| **Holdout** | Randomized control group for lift measurement. |
| **RAG** | Retrieval-Augmented Generation. |
| **Grounding verifier** | NLI entailment check. |
| **LoRA** | Parameter-efficient fine-tuning. |
| **Red-team** | Adversarial regression tests. |
| **Slot confidence** | Per-slot extraction confidence. |
| **Missing slots** | Slots the model could not fill. |
| **Nutritional hallucination** | Ungrounded nutrient/health claim. |
| **Medical escalation** | Routing medical questions to a vet. |
| **Prompt injection** | Malicious text in owner input. |
