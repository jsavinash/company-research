# User Help Center Guides

## 1. What is the coaching assistant?

It turns your description of your pet into a complete profile and explains the recommended plan in plain language — grounded in AAFCO/FEDIAF and product specs. It never chooses the diet; the recommendation comes from the constrained nutrition engine.

## 2. How do I describe my pet?

Type in natural language: species, breed, age, weight, conditions, allergies, preferences. The assistant asks at most one follow-up if something is missing.

## 4. What does the answer contain?

- **Plan:** formula + portion.
- **Rationale:** why this plan (grounded in KB).
- **Citations:** AAFCO/product spec references.
- **Disclaimer:** "nutrition guidance, not veterinary advice."

## 4. Common questions

**Q: Can it diagnose my pet?**
A: No. Medical questions route to a vet.

**Q: Can it choose a prescription diet?**
A: Prescription diets require a vet.

**Q: Why is it uncertain?**
A: Thin profile or low-relevance retrieval → safe generic guidance.

## 5. Troubleshooting

| Issue | Fix |
|---|---|
| Assistant slow | Retry; check status |
| "Not certain" | Provide more detail (weight, age) |
| Wrong plan | Report; vet can override |
| Don't understand | Ask a follow-up question |

## 6. Best practices

- Be specific (breed, age, condition).
- Cross-check with your vet.
- Report issues via support.
