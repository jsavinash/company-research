# Magic Moment and Aha Activation

## 1. The magic moment

The moment an owner types a messy description and gets a **complete profile + a warm, explained plan in seconds** — with the numbers coming from the solver, not the LLM.

> **Example:** "he's a chunky 3-yr-old lab, itchy paws, hates fish" → *"Because he's a 3-yr-old lab who's a bit heavy and reacting to chicken/fish, I picked a salmon-based sensitive-skin formula that still meets adult maintenance. Start with 312 g/day, transition over 7 days. This is nutrition guidance, not veterinary advice."*

## 2. Aha! moments

| Aha moment | What the user realizes |
|---|---|
| **First intake** | "I didn't have to fill a form — it understood me." |
| **First coaching** | "It explained *why*, not just *what*." |
| **Grounding** | "It cites AAFCO — I can trust it." |
| **Vet summary** | "My vet can endorse this." |

## 5. Time-to-value

| Milestone | Target |
|---|---|

## 6. Activation tactics

- **Guided first question** — pre-built examples.
- **In-context explanation** — "why this plan" panel.
- **Citations** — AAFCO/product spec references.
