# Core Loops and Habit Mechanics

## 1. Core value loops

### Loop 1 — The intake loop
```
Owner describes pet → LLM extracts profile → plan generated → coaching delivered → owner acts → feedback
```

### Loop 2 — The trust loop
```
Grounded coaching → citations → owner trust → adherence → repurchase
```

### Loop 3 — The feedback loop
```
Owner/vet accept/adjust/reject → labels → retrain → better intake/coaching
```

## 2. Habit mechanics

| Mechanic | Application |
|---|---|
| **Cue** | New pet, diet change, vet visit |
| **Routine** | Describe pet, get plan |
| **Reward** | Warm, explained plan |
| **Investment** | Feedback, repurchase |
| **Social proof** | Vet endorsement |

## 4. Retention drivers

| Driver | Mechanism |
|---|---|
| **Habit** | Embedded in feeding routine |
| **Switching cost** | Profile history, vet relationship |
| **Value** | Better nutrition, explained |
| **Trust** | Grounding + citations |

## 5. Retention metrics

| Metric | Target |
|---|---|
| Weekly active owners | ≥ 60% |
| Week-4 retention | ≥ 50% |
| Repurchase rate | Report |

## 6. Anti-patterns

- **Trust erosion** — a hallucinated claim hurts; mitigated by grounding.
- **Over-automation** — owners want control; vet remains authority.
